# 还款清单

本地离线的负债还款 PWA。静态文件位于 `dist/`，可部署到 HTTPS 静态托管。

## 还款计划

- 输入初始欠款、每月固定还款金额和初次还款日。
- 以初次还款日为锚点逐月生成还款计划。若某月没有该日（如 31 日），当月落在最后一天；下个月仍回到原始日期。
- 每期按固定金额计算，最后一期只取剩余欠款。还清后不再生成计划。
- 已过计划日默认视为已还。手动记录实际还款与默认计划取较大值计算累计已还，避免重复扣款。首页余额因此是估算值，应与账单核对。
- 金额均以整数分保存。应用不计算利息或手续费。

数据保存在当前浏览器的 `localStorage`，支持 JSON 导出和恢复。版本 1 数据会在读取时转换为版本 2：旧的“下次还款日”沿用为“初次还款日”，用户可编辑修正。
